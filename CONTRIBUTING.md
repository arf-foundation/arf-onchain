# Contributing to ARF Onchain

First off, thank you for considering contributing to ARF Onchain! 🚀

## What We're Building

ARF Onchain is a governance layer for autonomous AI agents on Monad. We're building:

- Smart contracts that enforce identity, policy, and risk boundaries
- A reference decision engine for risk scoring
- A dashboard for governance visibility
- An autonomous agent demo

## How to Contribute

### 1. Find an Issue

Check the [Issues](https://github.com/arf-foundation/arf-onchain/issues) tab. Look for:

- `good first issue` – beginner-friendly
- `help wanted` – active needs
- `week-2` – ExecutionGuard implementation

### 2. Join the Discussion

- Discord: DM @petterjuan
- GitHub Discussions: Open a thread

### 3. Submit a PR

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Write your code
4. Run tests: `forge test`
5. Push and open a PR
